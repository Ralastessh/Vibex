# 개발 일정 및 계획
- **김준수 — 네트워크 연결 및 백엔드**: Desktop Bridge, LLM CLI 어댑터, API 괸리, 보안, 네트워크
- **문희주 — UI/UX 디자인 및 프론트엔드**: iPad 앱, 디자인 시스템, 화면 흐름, 사용자 검증, 데모 연출

---

**협업 시 유의 사항**
최종 목표는 다양한 LLM 서비스의 오픈소스 지원이지만, 1차 시연 때까지는 대중적으로 사용되는 "Claude Code CLI를 비대화형으로 재개"를 소목표로 지정하여 개발

"이 화면에 뭘 보여줄지"는 문희주가 정하고, "그 값을 어떻게 얻을지"는 김준수가 정한다.
<예시>
- 문희주가 "테스트 결과를 초록/빨강으로 보여주고 싶다" -> 김준수가 `status: passed|failed|skipped` 제공
- 김준수가 "미커밋 변경이 있었다" 경고를 만듦 -> 문희주가 어디에 어떻게 띄울지 결정
- 새 필드가 필요하면 **API 구조를 먼저 고치고** 양쪽이 반영하기

## 2주차 — 프론트엔드 및 백엔드 구체화
일정: 7/27~7/31
목표: **각자 맡은 프론트엔드와 백엔드 본격 개발 후 API 통신 확인**

### 김준수

| 일 | 작업 | 완료 기준 |
|---|---|---|
| 1–2 | Claude Code 어댑터 개발 — 세션 탐색, resume, 실행 | 텍스트 명령으로 파일 수정 |
| 2 | 성공 판정 — 정상 요청과 비정상 요청을 보내어 권한 승인/거부를 함께 확인 | 회귀 테스트 |
| 3 | 출력 JSON 파싱 — 변경 파일·테스트 결과·질문 | 구조화 결과 반환 |

| 4 | Git으로 실행 전 상태 기록, 미커밋 변경 보존 | 예외 없이 처리되었는지 확인 |

| 일 | 작업 | 완료 기준 |
|---|---|---|
| 1–2 | PencilKit 캔버스 — 펜/형광펜/지우개/올가미, undo·redo | 터치펜으로 손글씨가 부드럽게 그려짐 |
| 2 | 떠 있는 툴바 — 도구/색/굵기 | 캔버스를 가리지 않음 |
| 3 | 스크린샷 불러와 그 위에 주석 | 배경 위 드로잉 |
| 3 | 캔버스 → PNG 합성 (배경 + 획) | 파일로 저장해 확인 |
| 4 | 프로젝트 목록·사이드바 완성 | 상태 점/배지 |
| 4–5 | 결과 화면, 대화 스레드 (mock) | 전 화면 이동 가능 |
| 5 | **백엔드와 연결** — 실제 서버의 프로젝트 목록 표시 | 실기기에서 목록 로드 |

### 통합 시 발견된 문제(해결 예정)
iPad 드로잉 앱이 PC 서버에서 프로젝트 목록을 받아 와야 함.

> 여기서 **평문 HTTP 차단(ATS)** 문제가 발생. iOS는 `http://`를 기본 차단하므로
> `Info.plist` 설정이 없으면 연결 자체가 안 된다고 추측됨.

## 최종 검증 리스트

1. iPad와 iMac이 서로 다른 네트워크에 있다
2. iPad에서 프로젝트를 고르고, 화면 위에 펜으로 수정사항을 그린다
3. 해석 결과를 보고 승인한다
4. iMac의 기존 CLI 세션이 재개되어 코드가 바뀌고 테스트가 돈다
5. 변경 파일과 테스트 결과가 iPad로 돌아온다
6. 도중에 연결이 끊겨도 재접속하면 결과가 있다
7. 원격에서 임의 경로를 지정할 수 없다
8. 기존 미커밋 변경이 파괴되지 않는다
